# Melvin Chipimo — profile site

A responsive one-page React profile with an editorial visual style, supplied photography, and no generated imagery. The professional summary and selected engagements have been aligned with the provided executive CV.

## Run locally

```sh
npm install
npm run dev
```

## Build for static hosting

```sh
npm run build
```

The deployable site is written to `dist/`. It has no server-side requirements and can be hosted on GitHub Pages or another static host.
